# 🗡️ Easy Hero

### Despierta sin memoria. Explora Zafias. Pelea de tú a tú.

*Un RPG por turnos que se juega en el navegador, con el alma de los clásicos como DragonFable:
una aldea con sus vecinos y sus encargos, combates de lado, venenos y sangrados, armas que cambian a tu héroe…
y una pregunta que nadie en Zafias quiere responder: ¿quién eres?*

## 🚧 Estado del juego

> [!NOTE]
> **Versión 1.12.0, sigue en desarrollo.** El foco es la **aventura**: Zafias se puede jugar de principio a fin, con
> Grask como primer muro y Feronius como jefe. La mazmorra sin fondo de las primeras versiones está aparcada (sigue
> en el código, pero no se puede entrar).

### ✅ Ya se puede jugar

- 🌅 **Una introducción**: despiertas sin memoria en unas ruinas, eliges tu nombre y caminas hasta Zafias
- 🧭 **Zafias**: aldea, las casas del camino, bosque, campamento goblin y la guarida del lobo; 41 paradas, goblins, lobos y dos jefes
- 🎭 **Diálogos de novela visual** con retratos, y una historia con misterio
- 📜 **Misiones y diario**: la principal y las secundarias, con su progreso
- ⚔️ **Combate de lado** con embestidas, números de daño y enemigos que se aprenden
- ✨ **7 efectos de estado**, con su icono sobre cada personaje
- 💧 **Maná, PH y barra de habilidades**: Bola de fuego y Grito de guerra
- 🎒 **10 armas** con rareza, elemento y efecto, un inventario al estilo DragonFable y un héroe que cambia con su arma
- 🛒 **Tienda**: armas, cristales de mejora, pociones, elixires, veneno, pan y las mejoras permanentes de La Forja
- 🧬 **Nivel permanente y estadísticas primarias**, repartidas por ti
- 📖🎒🏆 **Bestiario, colección y logros**, desde el menú de arriba
- 💾 **Guardado automático**, y exportar o importar tu progreso desde Opciones
- 📱 Funciona en ordenador y en móvil

<details>
<summary><b>🕳️ La mazmorra sin fondo (aparcada)</b></summary>

<br>

Las primeras versiones de Easy Hero eran un descenso por una mazmorra sin fondo: rutas de 16 pisos con combates,
cofres, hogueras, **15 eventos** con dos decisiones, sub-jefes y un jefe; **90 monstruos** con **22 variantes**,
**122 objetos** de 5 rarezas en 4 ranuras, el trofeo legendario de cada jefe y una semilla por partida. Todo sigue en
el código y en sus comprobaciones, a la espera de volver… quizá detrás de la cueva del sur. Su diseño está en
[docs/eventos.md](docs/eventos.md) y [docs/equilibrio.md](docs/equilibrio.md).

</details>

## 🛠️ Para quien quiera colaborar

<details>
<summary><b>💻 Probarlo en tu ordenador</b></summary>

<br>

Necesitas tener **Node.js** y **Python** instalados. Desde la carpeta del proyecto:

```bash
npm run dev      # abre el juego en http://127.0.0.1:8770
```

Para probar armas y efectos sin gastar oro, pon `freeShop: true` en `src/data/balance.js`: la tienda lo da todo gratis.

</details>

<details>
<summary><b>✅ Comprobar que todo funciona</b></summary>

<br>

```bash
npm install                        # solo la primera vez
npx playwright install chromium    # solo la primera vez
npm test                           # ejecuta todas las comprobaciones
```

Son 1265 comprobaciones automáticas. Las de la lógica del juego tardan unos segundos; las del navegador, unos minutos.

Para ver cómo está el equilibrio de la aventura: `npm run sim:aventura` juega miles de partidas con un bot.

</details>

<details>
<summary><b>🎨 Añadir arte</b></summary>

<br>

```bash
npm run sprites   # héroes, enemigos, fondos y armas en la mano (img/entrantes → img/sprites, img/bg)
npm run icons     # iconos, objetos, marcos de interfaz y retratos (img/icons, img/items, img/weapons, img/characters → img/ui, img/portraits)
npm run vn        # novela visual: revisa diálogos y retratos; «nuevo» crea un NPC con su retrato y «ver» saca capturas
```

Receta para meter un NPC con su retrato y su diálogo: [docs/novela-visual.md](docs/novela-visual.md).

</details>

<details>
<summary><b>🏷️ Publicar una versión nueva</b></summary>

<br>

```bash
npm run release              # ¿está todo sincronizado con la versión actual?
npm run release -- patch     # 1.11.0 → 1.11.1  (también minor o major)
```

Cambia la versión en todos los sitios a la vez y prepara el registro de cambios. Los pasos completos están en [docs/versiones.md](docs/versiones.md).

</details>
